# v0.21 — Connection Character

- Added source-envelope-following, pitch-aware sympathetic voices to explicit connections.
- Connected targets contribute material-specific secondary modes without independent note-on events.
- Link travel time and strength now respond to object distance.
- Links fade smoothly when removed or disabled.
- Reduced non-connected background coupling to improve contrast with explicit connections.
- Increased connected-object visual response.
- Preserved all five primary sound engines, existing delay/reverb/output chain, layouts, and settings.
- Kept the existing storage schema for backward compatibility.
