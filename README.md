# RESONANT OBJECTS v0.10 — KINETIC FIELD

iPhoneを横向きにして両手で演奏する共鳴楽器。外部ライブラリ、画像素材、サーバー側処理は不要です。

## 操作

- タップ: 触れた瞬間に打音。中央と外周では倍音の強さが異なります。
- 中心をドラッグ: 音を鳴らしつつ移動。隣接オブジェクトは衝突で押し出され、重なりを抑制します。
- **THREAD（新機能）**: 物体をドラッグして隣の物体の近くに置き、**約0.5秒保持**すると光の結合線ができます。結合した一方を叩くと、もう一方も弱く共鳴します。物体を十分離すと接続は自然に切れます。
- 1個につき最大2つの結合。自動で鳴り続けるシーケンサーではありません。
- 外周スライド: オブジェクトを動かさずに繊細な連続音へ移行します。
- 長押し: 弱い持続音。指を離すと自然に終了します。
- オブジェクト数: 7 / 9 / 11。切り替えても同じ画面内での半径は共通です。
- 素材アイコン（左から）: JEWEL / CANDY / CERAMIC / METAL。音・色・形状・衝突音が変わります。
- 鍵: オブジェクトの配置をロック。演奏は可能です。
- 右端のドットアイコン: 設定を表示。THREADのON/OFF、音名表示、音響設定、保存、配置リセット、LAB、描画品質などを格納しています。

## v0.10 での主な変更

- PLAY/MOVEを再分離せず、画面内で演奏、移動、結合を同時に実現。
- 近接保持によるConnectを導入し、**持続的な音響カップリング**と一回限りの小さな共鳴応答を追加。結合を描画上の線だけにしていません。
- 結合のプレビュー、伝達パルス、引き離しによる解除を追加。
- 衝突音を4素材で別々の倍音・長さ・ピッチ変化に変更。掴んだだけで広帯域ノイズを鳴らす処理はありません。
- 通常画面をアイコン中心に再設計し、音名、LAB、長い説明文、レンダラー情報を常時表示しない構造に変更。
- 保存形式 `resonant-objects-v010`。v0.9など旧形式の設定も読み込みます。連結情報は音数ごとに保存します。

## ファイル

- `index.html`：配布・GitHub Pages向け単一HTML（これだけで動作）。
- `source/audio.js`：Web Audio APIによるモーダル合成、接触音、持続・移動音、音声結合。
- `source/graphics.js`：WebGL 2 / WebGL 1のマルチパス描画、Canvas 2D代替、接続ライン。
- `source/interaction.js`：マルチタッチ、衝突、接続管理、設定、保存。
- `source/styles.css`：GUIのスタイル。
- `source/shell.html`：単体HTMLへのビルド用テンプレート。
- `build.py`：編集後の単一 `index.html` を再生成（Python標準ライブラリのみ）。
- `screens/`：ブラウザ画面の参考画像。

## 実行方法

GitHub Pagesのリポジトリ直下に `index.html` を配置します。iPhone Safariで横向きにし、発音体をタップするとブラウザのAudioContextが起動します。Safariの自動音声再生制約により、初回はユーザーのタップが必要です。

## 検証と制約

- JavaScript構文と、Chromiumでの基本GUI・タッチイベント・接続成立／解除・素材切替・7/9/11個切替を確認。
- Web Audioの起動および共鳴回路の生成をChromiumで確認。
- この実行環境ではWebGL描画が使えなかったため、スクリーンショットはCanvas互換描画です。WebGL 2/1のシェーダー処理とiPhone Safari実機の描画、マルチタッチ感、音質・遅延・電力消費は未検証です。
- 結合と共鳴は制限つきのモデルで、実際の物理衝突を厳密に解く物理シミュレーターではありません。
- 設定の保存には `localStorage` を使用します（端末/ブラウザ内）。プライベートブラウズなどでは保存できない場合があります。
