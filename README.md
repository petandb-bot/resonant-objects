# RESONANT OBJECTS v0.9 — LIVING MATERIALS

iPhone横向きで遊ぶ、Web Audio API ＋ WebGL 2/1 の共鳴楽器。v0.8.1からの機能を維持し、**4つの素材別音響と描画**を追加したバージョンです。

## 今回の要点

- **掴んだときのスネア風ノイズを削除**。以前の打撃音に重ねられていたごく短いホワイトノイズ源、およびスライド用ノイズ源を撤去。通常のタップは倍音を持つ柔らかなモーダル音のみ。ドラッグを離した瞬間の自動的な音の追加も停止しました。
- **接触すると短いガラス音**。物体の移動で接触した場合だけ、高域の短いサイン波合成による甲高い「チン」という共鳴音。ノイズは使いません。Contact ChimesからOFFにできます。連続接触の際の連打制限と、物体の押し合いによる重なり防止は継承。
- **JEWEL（ジュエル）**：v0.8.1の6成分モーダル合成の基本音程比を維持。透明な結晶／虹色の光学表現。淡い水色〜紫。
- **CANDY（キャンディ）**：短めの減衰、微細な音程バウンス。柔らかい丸形／弾性的な変形。ピンク〜オレンジの明るい背景。
- **CERAMIC（セラミック）**：温かみのある短めの非金属的な響き。マットな質感。生成色はサンド、セージ、テラコッタ。
- **METAL（メタル）**：非整数倍音を少し含む金属音。多面体、冷たい反射、深いブルーラベンダーの背景。
- **オブジェクト数**：7/9/11。従来どおり同じ画面サイズなら発音体は同じ直径。タップ・中心からのドラッグ・外周スライド・長押しがモード変更なしで可能。
- **音色とビジュアルの連動**：素材ボタンは画面上部に常時表示。素材を切り替えると、発音音色・オブジェクトの色／形・背景色が変化。通常の演奏UIは表示し続けます。Brightnessスライダーは選択した素材の内部音色調整です。
- **端末保存**：v0.9用キーで設定・オブジェクト配置・素材を保存。既存のv0.8.1以前の保存形式も読み込めるようにしています。

## 使用方法

1. GitHub Pagesに `index.html` を置く（サブディレクトリ構成不要）。HTTPSで開きます。
2. iPhoneは横向きで使います。最初にオブジェクトをタップすると音声が有効になります。
3. 画面上部の JEWEL / CANDY / CERAMIC / METAL を切り替えて演奏します。
4. 中心をタップすると打撃音、中央からドラッグすると押し合い、外周から指を動かすとグライド、長押しは柔らかな持続音になります。
5. TUNEから、Ring／Space／Bond／Bloom／Play Feel／Drag Sound／Glass Contact Pingなどを調整します。
6. `SAVE` で端末内に保存できます。リセットは配置だけを初期化します。

## 開発用ファイル

- `src/audio.js`：音声合成・共鳴・素材別音色・衝突音
- `src/renderer.js`：WebGL GPU描画とCanvas互換描画
- `src/app.js`：ポインター入力・物理衝突・保存・状態制御
- `src/style.css`：画面・色・スマートフォン表示
- `src/body.html`：UI構造
- `src/build.py`：Python標準ライブラリだけで単体 `index.html` を再生成
- `screens/`：素材別画面、演奏時の表示検証

更新後は `python src/build.py` で単体HTMLを再生成します。外部JavaScriptライブラリは使っていません。

## 検査と制約

- JavaScript構文：3ファイルとも`node --check`を通過。
- Chromiumの844×390、667×375、1280×720で、素材切替、7/9/11切替、画面表示、音源ノード生成を確認。実行時JavaScript例外は検出されませんでした。
- AudioContextで各素材の打撃音と衝突音の発音ノード生成を確認。通常の打撃・衝突でノイズ用BufferSourceを生成しないことを確認しています。
- 9オブジェクトのドラッグ操作で、押した相手も移動することを確認。
- **本環境ではWebGLコンテキストを取得できず、実GPUシェーダー表示は未検証**。画像はCanvas 2D互換描画。iPhone Safari実機でのWebGL・音色・レイテンシー・発熱も未検証です。
- ログイン・外部通信・個人データ収集はありません。保存はブラウザのlocalStorage内のみ。

## 仕様について

素材切替は**これから鳴る音**に作用します。すでに鳴り始めた余韻を途中で強制的に切り替える処理は行いません。既存のハンドパン的なJEWELを基準に、遊びの幅を増やす設計です。
