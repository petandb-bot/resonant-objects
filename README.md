# RESONANT OBJECTS v0.11 — PLAYFUL MATERIALS

iPhone横向きで演奏する、物体のタップ・移動・衝突・結合を音に変換するWebGL/Web Audio楽器。

## v0.11での重要変更

**音源を4つの独立したDSPエンジンへ分離しました。** v0.10以前のような同一モーダル合成エンジンのパラメーター違いではありません。

| Material | エンジン | 音の方向性 | ビジュアル・運動反応 |
|---|---|---|---|
| JEWEL | `JewelModalEngine`：6本の独立モード発振器 | 透明で柔らかい倍音、長めの余韻。従来の音色を基準に継承 | ファセットの内部光、共鳴リング |
| CANDY | `CandyElasticFMEngine`：周波数変調＋サブトーン＋ピッチ回復 | 弾む短い音、連打で変化するFMの硬さ | 丸いスクエア状の形、伸縮する輪郭 |
| CERAMIC | `CeramicWaveguideEngine`：短い励起信号→減衰付き短遅延回路、補助の胴鳴り成分 | 乾いた陶器の打音、短く明瞭 | マットな丸み、多角形の小さい振動 |
| METAL | `MetalInharmonicFMEngine`：複数の非整数比FM | 鋭い金属的な倍音、複雑な減衰 | 鋭い微小振動、反射線 |

`source/material_engines.js` には共通のイベント管理と4種類の **独立した音源グラフ** があります。発音・衝突の経路はどちらも素材別エンジンを通ります。背景のSpace/Bloom、音量制御、共鳴伝達バスなどの共通インフラは維持しています。各素材でConnectの共鳴フィルターの周波数構成も異なります。

`CERAMIC` の短いフィードバックディレイには低ゲインと減衰フィルターを設定し、過大発振を防止。スネア風の広帯域ノイズは使いません。

## 操作

- **タップ**：触れた瞬間に発音。中心と外周で倍音の量が変わる。
- **中心ドラッグ**：物体を演奏しながら移動。周囲の物体を押す。衝突時のみ素材別の短い接触音。
- **近接保持（約0.5秒）**：近くの物体とConnect。光の線が生まれ、相互の共鳴経路も変わる。引き離すと解除。
- **外周スライド**：短い滑らかな連続音。素材により倍音構成が異なる。
- **長押し**：小さな持続音。
- **上部**：4つの素材アイコン、7/9/11音、配置LOCK、設定。通常画面は説明表示を減らしたまま。

オブジェクトは7・9・11音で同一半径。タッチ用の中心と外周の判定は継承。操作モードは分割しません。

## 比較音源

`sound-check/` には **D4（MIDI 62）、ベロシティ0.8、外周寄り0.5** の同一条件でWeb AudioのOfflineAudioContextから生成した4つのモノラルWAVを収録。後処理・正規化なし。各音源方式の違いを比べられます（実機スピーカーでは音量・音色が異なります）。

## 実行

- `index.html` のみでGitHub Pagesに配置して動作。外部CDN・依存パッケージ不要。
- iPhone Safariでは横向きで開き、最初にタップして音声を有効化。画面回転の固定はブラウザ/OSに依存。
- `source/` を編集した場合、`python build.py` で単体HTMLを再生成。

## ソース構成

- `source/material_engines.js` : JEWEL / CANDY / CERAMIC / METAL の独立DSPエンジン
- `source/audio.js` : Web Audioバス、音声合成の呼び出し、共鳴カップリング、エフェクト
- `source/graphics.js` : WebGL 2 / 1、マルチパス描画、衝突の視覚表現、Canvas 2D代替
- `source/interaction.js` : マルチタッチ、押し合い、Connect、UI、保存
- `source/styles.css`, `source/shell.html` : GUI、単体HTMLテンプレート
- `build.py` : ビルド

設定保存キーは `resonant-objects-v011` に変更し、旧 `v010` などの保存データを読み込めるようにしています。

## 検証範囲と制約

- JavaScript構文検査、Chromiumで素材切替・音声起動・7/9/11音・Connectの成立/解除・押し合いを確認。
- 4音源についてOfflineAudioContextで実際にPCM波形を生成し、ピーク値と時間別実効値を比較。素材ごとに発音エンベロープと波形特性が異なることを確認。
- **WebGLのGPU描画およびiPhone Safari実機での演奏感・電力消費は未検証です。** この検証環境ではWebGLコンテキストが使用できず、スクリーンショットはCanvas代替表示です。
- 音質の主観評価・物理モデルの実物再現精度は検証していません。CERAMICの発音は他の長音素材よりかなり短く、聴感音量は異なります。
