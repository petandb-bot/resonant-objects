# RESONANT OBJECTS v0.8 — ONE PLAYING FIELD

iPhoneを横向きにして両手で演奏する、WebGL + Web Audioによる実験的な共鳴楽器。v0.7のモーダル合成、Live Resonance、Bloom、AURA/TRACEを引き継ぎ、演奏と移動のモード切替をなくしました。

## 起動・配布

- **index.html だけで動作**。外部ライブラリ、音声サンプル、インターネット通信は不要です。
- iPhone SafariではGitHub Pages等のHTTPS配信で開いてください。画面を横向きにして、発音体に初めて触れたとき音声を有効化します。
- ファイルの更新は `src/` 以下を編集し、プロジェクトのルートから `python src/build.py` を実行。出力された `index.html` を公開してください。
- WebGL2 → WebGL1 → Canvas 2D互換描画の順で初期化します。音声合成はWeb Audio APIで処理するため、GPUに依存しません。

## v0.8 のジェスチャー（単一の演奏画面）

| 操作 | 動作 |
| --- | --- |
| タップ | **指を置いた瞬間に発音**。中心は柔らかく、外周ほど倍音が増える（PLAY FEELがONのとき）。 |
| 中心（半径の約69%以内）からドラッグ | 15 CSS px を超える移動で発音体をつかんで移動。速度と距離が摩擦音／連続共鳴に反映される。 |
| 外周からスライド | オブジェクトの位置を変えず、指の速度・位置によって摩擦音や音程を変える。別の発音体に触れるとその音も鳴る。 |
| 長押し | 約270msで柔らかい持続音が立ち上がる。移動し始めると停止。 |
| 接触させる | 動かした発音体が他の発音体に接近して接触すると、**一度だけ短い接触音**が鳴る。引き離してから再接触すると再発音する。 |
| 指を離す | ドラッグ速度が十分に高い場合に弱いリリース音。その後、連続音声回路を停止・解放。 |

タップ時の発音をドラッグ判定まで遅らせない構造です。意図しない大移動を避けるため、15 CSS px未満では位置を変更せず、移動中も他の発音体の中心を覆わないように制限しています。他の発音体自体を押し動かす物理シミュレーションは現時点では行いません。

**LOCK**: 配置だけを固定し、タップ・外周スライド・長押しは継続できます。再びUNLOCKEDにすると移動可能。

**CONTACT CHIMES**: 接触音をOFFにして無音で配置可能。**DRAG SOUND**、**PLAY FEEL**、**EXPRESSION**、**HOLD**も独立調整できます。これらは音源自体の主要なモーダル合成を変更しません。

## 7・9・11個の配置

- 同じ端末・同じ画面サイズでは **7 / 9 / 11 の発音体直径は全て同じ**。音数を増やしても個体を縮小しません。
- 中心1個＋周囲6/8/10個。11個では輪の位相を18度回し、左右の接近を回避します。
- 画面サイズに応じて全モード同じ半径に再計算します。位置を保存したオブジェクトは復元位置を優先します。
- LABの直径と隙間はCSSピクセルの幾何学計算で、タッチ成功率の実測値ではありません。

## 設計・コード構造

- `src/app.js`: タッチ状態遷移 `pending → drag / glide`、個別ポインター追跡、接触検出、配置、設定、LAB。
- `src/audio.js`: 既存の6成分モーダル音源、近接打撃、連続共鳴、Hold、摩擦音回路。v0.8で接触インパルスと短いリリース音を追加。
- `src/renderer.js`: WebGL2/1（ジオメトリー → GPU残像蓄積 → 光学合成）＋2D互換描画。ドラッグ中の発音体のハローを強調。
- `src/style.css`、`src/body.html`、`src/build.py`: スマートフォン優先のGUI、単体HTML生成。

設定は `localStorage` の `resonant-objects-v08` に保存。v0.7以前の保存データから読み込めるようにしています。保存はサイトの同一オリジン単位です。

## 動作確認

- Node.jsで3個のJavaScriptソースを構文検査：通過。
- Chromiumの844×390 / 667×375 / 1280×720の表示：起動、7/9/11切替、TUNE / LAB、LOCK、中心ドラッグ、配置維持を確認。
- LAB表示値（初期配置）：844×390で直径64px共通、隙間は7:38px / 9:22px / 11:17px。667×375で直径61px共通、隙間は7:36px / 9:21px / 11:10px。
- 外周スライドで元の発音体の位置が変わらず、タッチが別物体へ渡るとスライド回数が増えることを確認。
- 発音体同士の接触イベント、離脱後の再発音制御、2本指入力の認識（模擬PointerEvent）、JavaScript例外なしを確認。
- 検証用ChromiumではWebGLのGPUコンテキストを取得できなかったため、付属スクリーンショットはCanvas 2D互換描画です。**実際のWebGLシェーダー実描画、iPhone Safari実機、端末スピーカーの音質・発熱・処理遅延は未検証**。
- 検証はオリジンのないHTMLを使ったため、実ブラウザの `localStorage` 保存動作は未検証。GitHub Pages等のHTTPSサイトで確認してください。

## 音響の安全性

接触音は最大音量を抑え、フィードバックは既存のゲイン制約・ローパス・コンプレッサーに依存します。長時間演奏や多点タッチ時の音量・安定性は実機で点検してください。開始時は音量を低めにしてください。
