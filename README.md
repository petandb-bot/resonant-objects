# RESONANT OBJECTS v0.11.2 — GENTLE CONTACT

v0.11.1 WAVE をベースに、ドラッグ時の不要な打撃音と衝突音を見直した安定化版です。5素材、Wave accents、WebGL描画、7/9/11個、物体の押し合い、Connect、長押し、スライド演奏を維持します。

## 変更点

1. **中心から掴んでドラッグする操作は無音で開始**します。触れた直後には打撃音を再生せず、実際にタップした場合は指を離したタイミングで1音だけ鳴らします。外周からのタップ・グライドは従来どおり即時発音です。
2. **中心での長押しは持続音のみ**。長押しを離すときに打撃音が重なることはありません。
3. **移動中の合成発振音は初期状態でOFF**。旧バージョンの保存データでONになっていた場合も、v0.11.2初回読み込みではOFFに移行します。設定内の「Soft motion tone」で意図的にONにすることはできます。通常のスライド演奏は維持。
4. **衝突音を再設計**。従来の素材別FM/短い高域打撃イベントを衝突時には使わず、独立した小音量の正弦波モード共鳴で生成します。JEWELはガラスの小さな澄んだ音、CANDYは丸い接触音、CERAMICは控えめで乾いた響き、METALは穏やかな金属共鳴、WAVEは柔らかい長めの音です。
5. **接触の誤発音防止**。一定以上の移動速度と新規接触を条件にし、同じペアは330ms以内に再発音しません。1回のドラッグ更新で発音させる衝突は最大1組。
6. **Connect/Live Resonanceを維持**。接触によって発生したわずかな振動を共鳴経路にも伝えます。

## 使い方

- オブジェクトの**中心を短くタップ**：指を離したときに1音鳴る（ドラッグとの誤認防止のため）。
- **中心からドラッグ**：オブジェクトを押し動かす。掴む／離すだけでは発音しない。
- **別のオブジェクトに衝突**：十分な速度のときだけ、小さな素材固有の接触音が鳴る。
- **外周をタップ／スライド**：従来の即時打撃・滑奏。
- **長押し**：柔らかな持続音。
- **Connect**：近づけて保持すると結合し、共鳴が影響し合う。

右上の設定から、衝突音をOFFにすることもできます。原音と比較する場合は「Gentle material collision」を切り替えてください。

## 動作確認

- JavaScript構文検査通過。
- Chromiumブラウザ内で7/9/11の全配置について、ドラッグ開始時の打撃発音回数0、通常タップ1、長押しの余計な打撃0を確認。
- 9個モードで物体を隣へ押し当て、接触音1回、ドラッグ終了時の打撃0を確認。
- ChromeのOfflineAudioContextで5種類の衝突音を直接生成してピークを測定。いずれも開始波形は0から立ち上がり、過大ピークは検出されませんでした。
- `sound-check/gentle_material_contacts.wav` は実装したエンジンの**JEWEL → CANDY → CERAMIC → METAL → WAVE**の接触音を順に並べた試聴用WAVです。確認用の非マスタリング音源であり、アプリのマスター音量・空間処理を含みません。
- 検証用ChromiumではWebGLが有効にならないため、画面プレビューはCanvas 2D代替描画です。**iPhone Safari上での音質、GPU描画、レイテンシーは未検証**です。

## 公開方法

- GitHub Pagesのルートに`index.html`を配置してください。外部ライブラリは不要です。
- 編集版は`source/`内の`material_engines.js`・`audio.js`・`graphics.js`・`interaction.js`・`shell.html`・`styles.css`で管理し、`python build.py`で単体HTMLを再構築できます。
- 設定保存キーは`resonant-objects-v0112`です。古いデータは自動的に読み込みますが、移動音だけ安全側のOFFへ移行させます。
