# RESONANT OBJECTS v0.7 — PLAYFUL TOUCH

iPhone 横向き演奏を中心にした実験的な共鳴楽器。v0.6 のモーダル合成とマルチパス WebGL 描画を維持し、タッチ位置・スライド・Move の音響表現を追加しました。

## 起動

- `index.html` をブラウザで開き、画面上の発音体を押して音声を有効化します。
- 推奨は iPhone Safari / GitHub Pages（HTTPS）。横向きで使用します。端末によっては画面の自動回転設定を変更してください。
- オフラインでもライブラリをロードせず動作する単体 HTML です。ソースの変更後は `python src/build.py` で再生成できます。
- Safari はユーザー操作まで AudioContext の再生を制限することがあります。最初のタッチが必要です。

## v0.7 で追加した演奏

1. **中心と外周** — 外周を叩くと高い振動モードが強くなり、音が明るくなります。
2. **GLIDE / RUB** — 指を8 CSS ピクセル以上動かすと、指の速度・位置・距離に応じて弱い摩擦音が生成されます。指が止まれば減衰し、離すと音声ノードを解放します。別のオブジェクトへ渡ると従来どおり打撃音も鳴ります。
3. **MOVE SOUND** — Move 中に音が欲しい場合だけ、弱い摩擦音を追加します。距離が近い発音体の影響をわずかに受け、従来の結合回路も移動中に更新します。
4. **PLAY FEEL** — 新しい表現を ON/OFF。OFF では v0.6 の静かな打撃音・持続音へ近い動作になります。
5. **EXPRESSION** — 0〜100で表現量を制御。初期46。極端な音量の跳躍を避けるため、連続音は短い打撃音より控えめに設定。

## その他の操作・維持した機能

- PLAY：タップ／タップ位置による音質差／スライド／長押し
- MOVE：発音体の移動・距離連動／MOVE SOUND の ON/OFF
- TUNE：Material / Ring / Space / Bond / Bloom / Expression / Live Link / Hold / GPU Aura / GPU Trace
- 7・9・11音切替、3音階、3シーン、Shuffle、端末内保存、演奏性LAB
- LABの「Rub」「Move」は各ジェスチャーの回数。CSSピクセルの直径・隙間は推定値で、人間工学的な合否ではありません。11音の初期サイズをわずかに縮小し、隣接オブジェクトが重ならないよう調整。

## 音響・映像アーキテクチャ

`src/audio.js` — Web Audio API / 6部分音のモーダル合成、近接打撃、連続共鳴タンク、Hold、独立した短命な摩擦音声回路。指を離す・モード変更・表示非表示で音声を停止・解放。

`src/renderer.js` — WebGL2 / WebGL1。ジオメトリー、テクスチャへの時間的残像蓄積、光学的コンポジットの3パスを維持。ジェスチャー強度のシェーダー入力を追加。取得できない場合は Canvas 2D 代替描画。

`src/app.js` — タッチ状態機械・接触速度・距離・配置・LAB・保存。音声の操作にはフレームループを使わず、Web Audio の AudioParam スケジューリングを利用。

`src/style.css`, `src/body.html`, `src/build.py` — レイアウト、操作部品と単体HTMLのビルド。

## 検証

- Node.js による3つのJavaScriptソースの構文検査：通過。
- Chromium による 844×390 / 667×375 相当の横向きレイアウト、Play/Move/7・9・11切替、TUNE、LAB、タッチ・スライド操作：通過。JS例外なし。
- Chromium 上の Web Audio：初回タップによる running 状態を確認。スライド中のジェスチャー音声回路は 1、離した後 0。Moveでも同様。モード切替後の指状態 0。
- 検証環境の WebGL コンテキストは利用不可。掲載の画面プレビューは **Canvas 2D 代替描画**。WebGLシェーダー本体・iPhone Safari実機・スピーカー音質・レイテンシーは **未検証**。
- 検証でのHTMLはメモリ上の不透明オリジンで表示したため `localStorage` は利用できず、保存機能のブラウザ実動作は未検証。GitHub Pages の HTTPS オリジンで使用してください。

## 注意点

- 大音量時は端末スピーカーで音割れが起こり得ます。音量を低くして開始し調整してください。
- 3D描画品質設定 Eco / Balanced / High は処理速度の改善を意図した設定ですが、iPhone 実機での GPU 性能測定はまだ行っていません。
- v0.8 以降で予定している JEWEL / CANDY / CERAMIC / METAL の材質別音源・ビジュアル、背景Atmosphereは、今回のv0.7には未実装です。
