# RESONANT OBJECTS v0.8.1 — WebGL 修正／物理衝突

iPhone横向きで演奏するRESONANT OBJECTS v0.8の**不具合修正版**です。音源はv0.8から変更していません。旧v0.8の保存データを読み込めます。

## 修正した黒画面の原因

`src/renderer.js` の `drawScene()` が、存在しない変数 `n` を使って `uMove` ユニフォームを設定していました。WebGLコンテキストは正常取得され、`WEBGL2 GPU` が表示されても、最初の描画時に `ReferenceError` が発生し、キャンバスは黒いまま、HTMLの音名ラベルだけが残ります。

v0.8.1では、`uMove` を各発音体の描画ループ内で設定するよう修正しました。

また、初回GPUフレームを1ピクセル検査し、WebGLの描画エラー／黒フレーム／コンテキスト消失時にはCanvas 2D代替描画へ切り替えます。これにより、描画異常時に音名だけの黒画面で停止することを避けます。**iPhoneのWebGL描画は実機未検証です。**

## 新しいオブジェクト衝突

- モード切替なし：タップで演奏、**中心からドラッグで移動、外周からスライドで音色変化**。従来の操作は変えません。
- 中心を動かして別の物体に当たると、**その物体を押して動かします**。押された物体はさらに別の物体を押せます。
- 位置ベースの円形衝突制約を反復計算し、物体間に約3 CSS pxの隙間を保つようにします。端に近い場合は指で引いている物体の位置も少し譲らせ、壁やほかの物体を突き抜けないようにします。
- 移動を小さなステップに分割し、速いドラッグで発音体をすり抜けないようにします。
- Contact Chimes のON/OFFは**衝突音だけ**の切替です。OFFでも重なりを防ぎ、押し合う動作は継続します。
- 接触音は同じ接触で連打されないように制限し、1回の移動イベントにつき最大2回までにしています。
- 7・9・11個は引き続き**同一画面内で発音体のサイズを共通**にします。
- 保存・リサイズ時の重なりを補正します。位置を保存したオブジェクトの配置も継承します。

この実装は**重なり防止＋押し合い**の処理です。剛体シミュレーションのような慣性、跳ね返り、質量差まではまだ実装していません。タップに使う楽器として、静止時の位置が安定することを優先しています。

## 実行方法

1. ZIPを展開するか、`index.html` をGitHub Pages上の同名ファイルと置き換えます。
2. iPhoneを横向きにし、Safariで開きます。初回のタッチでWeb Audioの再生が有効になります。
3. 画面下部に `v0.8.1` と表示されるか確認してください。古い画面が残っている場合、再読み込みしてください。
4. GPUラベルが `WEBGL2 GPU` / `WEBGL1 GPU` ならGPU描画、`2D COMPATIBILITY` なら互換描画で動作しています。

ソースは `src/audio.js`、`src/renderer.js`、`src/app.js` などに分割されています。`python src/build.py` で `index.html` を再生成できます（追加ライブラリ不要）。

## 検証内容

- JavaScript構文検査：`audio.js`、`renderer.js`、`app.js` すべて通過。
- Chromiumの844×390でCanvas代替描画、7/9/11切替、9音でのドラッグと押し出し、エラーのない動作を確認。
- 衝突計算をコードから取り出して実施した自動テスト：844×285、667×270、1050×830の演奏領域で、各7/9/11音、壁付近を含むドラッグ経路25回×24ステップを試し、円形衝突の許容範囲を超える重なりは検出されませんでした。
- **検証環境ではWebGLコンテキストが取得できず、WebGL実描画・iPhone実機の音質／遅延は未検証です。** 画像プレビューはCanvas 2D代替描画です。

音声処理はWeb Audio API、グラフィックスはWebGL（利用できない場合はCanvas 2D）です。
