# RESONANT OBJECTS v0.13.0 — BLACK SIGNAL

## UI
- Completely new dark, vector-based WebGL geometry (no glowing plastic or jewel gradient).
- Five material-specific symbols and colors, with restrained sound-energy response.
- Connection traces have fine colored lines, clear endpoints, and event-driven directional pulses.
- WAVE remains a *layer* shown by a dotted extra ring, not a replacement.
- Minimal icon toolbar, settings remain behind gear, 7/9/11 same object size.
- Matching Canvas 2D backup visualization (WebGL is the default).

## Audio / interaction
The sound engine and pointer / collision / Connect logic are inherited unchanged from v0.12.4. No new electronic click, collision, or animation-triggered sound events. Five engines, WAVE layer, four reverbs, save, playability lab retained.

## Deploy
Copy index.html to the root of a GitHub Pages repository and load from iPhone Safari in landscape.

## Tests
