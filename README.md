# RESONANT OBJECTS v0.6 — GPU Resonance Field

iPhoneの横向き画面で演奏できる小さな共鳴楽器。v0.5のモーダル合成、タップ／スライド、長押し、Move、7/9/11切替、Live Resonance、Bloom、音階、シーン、LABを維持し、**描画の主系統をWebGLマルチパスに再構成**しました。

## 実行

- `index.html` 単体をGitHub Pagesのルートに配置すれば公開できます。外部ライブラリ、CDN、サーバーAPIは不要です。
- iPhoneのSafariで表示し、画面回転ロックを解除して横向きにします。最初の演奏操作でWeb Audioを有効にします。
- 分割されたコードは `src/` 以下。`python build.py` で `index.html` を再生成できます。
- `screens/` は検証環境によるスクリーンショットです。**GPUが利用できない検証環境のためCanvas互換描画であり、WebGLの実描画サンプルではありません。**

## WebGLの新しい処理

1. **Pass 1 Geometry** — GLSLシェーダーで背景・結晶状の発音体を描画。発音体間の結合をGPUの細い三角形リボンとして描画。
2. **Pass 2 Resonance Field** — 半解像度のテクスチャ2枚を毎フレーム交互に使用（ping-pong framebuffer）。発音体のエネルギーと位置をシェーダーへ渡し、伝播する共鳴波、緩やかな移動、時間的な残像を合成。旧フレームのテクスチャは減衰していきます。
3. **Pass 3 Optical Composite** — 元の画像、近接サンプルによるグロー、共鳴フィールドを最終合成。高輝度領域は簡易トーンマップで抑制。

WebGL2を優先し、利用できなければWebGL1（GLSL ES 1.00互換）を使います。WebGLを取得できない端末ではCanvas 2D互換描画へ切り替えます。また、FBO（フレームバッファ）を用意できなかった場合は、WebGLの直接描画で動作を継続します。画面上のグラフィックス表示には使用中の方式が表示されます。

WebGLは**視覚処理**であり、音声処理には使用しません。音声は引き続きWeb Audio APIで動作します。

## v0.6で追加された操作

- **GPU AURA**: 光のにじみや明るい領域の拡散量。音には影響しません。
- **GPU TRACE**: 共鳴波の時間的残像の強度。音には影響しません。
- **Quality**: Eco / Balanced（初期） / High。描画解像度上限と最大ピクセル数を切り替えます。長時間の演奏や発熱が気になる場合はEcoを選んでください。
- スマートフォンではTUNE内、デスクトップの広い画面では右側のGPU FIELDパネルから操作できます。
- v0.5の保存データを読み込み可能。v0.6では描画品質、Hold、Live ResonanceのON/OFFも保存します。従来の設定に影響しないよう、新しいlocalStorageキーを使います。

## 技術上のポイント

- 静止時に無制限で描画せず、音の減衰・残像がある時間にのみフレームを更新する設計。
- ピンポン方式で描画先のテクスチャを同時に読み書きしない構成。
- 再描画ターゲットはリサイズ・画質変更時に再生成・解放。
- WebGL context lost/restoredを受け取ってリソースを作り直す処理を備える。
- 結合線と共鳴フィールドの描画はGPU処理。WebGL正常時、Canvas 2Dオーバーレイは使用しません。
- 音量やオーディオ波形をGPUへ直接流してはいません。エネルギーは演奏トリガーと減衰から計算した表示用の近似値です。

## 動作検証と残課題

- JavaScript構文をNode.jsで検査。Chromiumで `844×390`、`667×375`、`1280×720`、`390×844` を表示し、7/9/11切替、Move、TUNE、パラメーター更新、画質変更、LABの切替、JavaScript例外なしを確認しました。
- 検証環境はWebGLコンテキストを取得できないため、**GPU描画およびGLSLの実機コンパイルとフレームレートは未検証**です。GitHub Pagesに配置し、iPhone Safariで実際に`WEBGL2 GPU`または`WEBGL1 GPU`と表示されるか確認してください。
- 検証環境の `about:blank` ドキュメントはlocalStorageが利用できないため、保存の永続化は今回のブラウザテストでは未検証です。GitHub Pages（HTTPSオリジン）で確認してください。
- iPhone内蔵スピーカーでの実音、マルチタッチの低遅延、WebGLの消費電力、GPU負荷は実機確認が必要です。
- 履歴テクスチャの処理は視覚用のエフェクトです。音源の物理共鳴モデルそのものがGPUに移行したわけではありません。
