# RESONANT OBJECTS v0.5 — The Listening Field

iPhoneを横向きに持って、7・9・11個の幾何学的な発音体を両手で演奏する小さなWeb楽器。v0.4のモーダル合成を基本として、音声信号による連続共鳴、長押し演奏、独立したBloomエフェクトを追加したバージョンです。

## 起動と公開

- **GitHub Pagesなら `index.html` 1ファイルのアップロードだけ**で動作します。外部ライブラリ・サーバーAPI・ログイン不要。
- iPhone Safariでページを開き、画面回転ロックを解除して横向きにしてください。最初のタップでAudioContextが起動します。
- WebGL 2/1を優先し、描画に使えない場合はCanvas 2Dに切り替えます。音声合成はWeb Audio APIでWebGLとは独立しています。
- `src/`は保守しやすい分割ソース、`build.py`を実行すると単体 `index.html` を再生成します。`screens/`はブラウザで取得した画面です。

## 演奏

| 操作 | 内容 |
|---|---|
| PLAY | 発音体をタップして短い柔らかな打撃音。複数指での同時演奏に対応 |
| スライド | 押したまま隣の発音体に移動すると新しい音を鳴らす |
| 長押し（新） | 約270ms経過後に弱い持続音が立ち上がり、指を離すと約140msでフェードアウト。HOLDをOFFにできる |
| MOVE | 発音体をドラッグし、近接する他の物体との共鳴関係を変更。ドラッグ中も結合量を更新 |
| RESET | MOVE中、配置だけを初期状態へ戻す |
| 7 / 9 / 11 | 画面上部から音数変更。演奏時のヒット領域と音数の比較に使う |
| TUNE | 小さな横向き画面で全音響パラメータ、音階、動き、シーンなどを調整 |
| LAB | 7/9/11の最小サイズ・物体間距離・タップ等の簡易操作ログを表示 |

## 音色とエフェクト

- **MATERIAL**：柔らかい金属〜明るいガラス。v0.4からモード比と発音カーブを維持。
- **RING**：音源の各部分音が自然に減衰する長さ。
- **SPACE**：3本の短い初期反射。初期値0（従来のドライ音）。
- **BOND**：打撃時の近隣発音体の励起量、および連続共鳴回路の結合強度。
- **LIVE LINK（新）**：音声信号が隣接する別の物体の共鳴フィルターを励起する回路。3つの固有モードを持つ共鳴タンクを物体ごとに常設し、各発音体から近い最大3つへ、遅延・ローパス・制限付きゲインを介して振動を伝達。OFFでv0.4型の打撃時Bondのみを残す。
- **BLOOM（新）**：別の残響系。2本の異なるディレイ、ローパス、抑制されたクロスフィードバックによる短〜中程度の拡散した余韻。初期値0。SPACEと独立。
- **HOLD（新）**：長押し時の持続音をON/OFFできる。これも原音と独立。
- **OUTPUT**：マスター音量、コンプレッサーを維持。

### 保存／互換性

SAVEはブラウザのlocalStorageに保存します。今回新しいキー `resonant-objects-v05` を使用し、まだ保存していない場合にはv0.4の保存データ `resonant-objects-v04` も読み込みます。音数、音階、位置、パラメータ、Move以外の演奏設定を保存できます。初版の音程（D minor 9音）は変更していません。

3つのScene：Glass garden（原音優先）、Blue hour（長い余韻）、Little sun（明るい音）。SHUFFLEは音程や位置を保持したまま音響パラメータを変更します。

## 実装ノート

- `src/audio.js` — Web Audioによるモーダル音源・共鳴タンク・効果処理・発振器管理。最大28音声バンク、長押し発振器最大5組。
- `src/renderer.js` — GLSL ES 1.00のWebGL 2/1共通シェーダー、光学的な幾何形状、Canvas 2Dフォールバック。線・音の伝播はオーバーレイとして描画。
- `src/app.js` — 画面サイズ、演奏、Move、長押しタイマー、保存、パラメータ、LAB。
- `src/style.css`, `src/body.html` — レスポンシブUI。
- 連続共鳴は純粋な物理モデルではなく、各音源の固有周波数に調整したバンドパス＋遅延ネットワークです。強い自己帰還を避けるよう設計していますが、すべての端末でのピーク耐性・CPU使用量は未計測です。
- MOVE時に変化させるのは結合ゲインであり、既存のボイスを途中で再ピッチしているわけではありません。
