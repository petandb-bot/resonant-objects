# RESONANT OBJECTS v0.4 — Luminous Geometry

iPhoneの横向き画面を両手で演奏する、9つの共鳴体を中心にした実験的なWeb楽器。

**初版から好評だった音響エンジンの音色を保持**しつつ、旧版の石風のGUIを幾何学的な光学オブジェクトに変更したバージョンです。描画にはWebGL 2 / WebGL 1を用い、利用できない環境ではCanvas 2Dへ切り替わります。外部ライブラリとネットワークアクセスは不要です。

## 起動

- `index.html` をGitHub Pagesにアップロードしてください。GitHub PagesのURLをiPhone Safariで開いて横向きにします。
- 初回のタップでWeb Audioが有効になります。自動再生の制約により、ロードと同時に発音はしません。
- 横向き推奨（縦向きの小さなスマートフォンには回転案内が表示されます）。
- **index.htmlのみ**でも動きます。`src/`は読みやすさと将来の変更のための元ソースであり、`build.py`で単独HTMLを再生成できます。

## 操作

| 機能 | 説明 |
| --- | --- |
| PLAY | 物体をタップ、滑らせる、複数指で同時に押す |
| MOVE | 物体をドラッグして配置を変更。変わった距離がBondにも反映される |
| RESET | MOVE中、現在の配置だけを初期化 |
| TUNE | 小さい横向き画面で音源パラメータと追加機能を表示 |
| MATERIAL | 柔らかい金属から明るいガラスへ。モーダル合成の部分音を調整 |
| RING | 物体そのものの余韻。リバーブの代替ではない |
| SPACE | 3本の初期反射ディレイ。初期値0（従来のドライ音） |
| BOND | 近くの物体の共鳴励起強度 |
| OBJECTS | 7 / 9 / 11音、中央＋外周の配置を比較 |
| TUNING | D minor / C pentatonic / F lydian |
| MOVEMENT | Still / Float / Orbit。図形だけを穏やかに動かし、タッチ領域は固定 |
| SCENE | 原音重視のGlass garden / Blue hour / Little sun |
| SHUFFLE | 音階・位置を変えずに音質4項目だけを乱数変更 |
| SAVE | 現在の音色、音数、配置、動きなどを端末内localStorageに保存（GitHub Pages等の通常のWebページで有効） |
| LAB | 発音体の直径、最小間隔、タップ数、空振り、スライド数、同時接触数を比較 |

PCでは数字キー `1`〜`9`（11音時は `0` と `-` を追加）でも演奏できます。

### 音源の継承内容

- v0.3のD minor 9音を維持：D3, A3, Bb3, C4, D4, E4, F4, G4, A4。
- 主な部分音の比率、6成分のサイン合成、打撃ノイズ、減衰カーブ、コンプレッサーの値を維持。
- 最大30の発音バンク。音を鳴らし終えた発振器/ノードは `onended` で開放。
- SPACEは従来同様、ドライに並列で加算する小規模な初期反射処理。長いリバーブやエフェクトチェーンはまだ未実装。
- Bondは打撃時の励起方式を継承し、連続結合型の物理モデルは今後の候補。

## ファイル

- `index.html` — 依存ファイルなしの公開用アプリ。これだけをGitHub Pagesに置ける。
- `src/audio.js` — 音源、空間処理、ボイス寿命管理。
- `src/renderer.js` — WebGLシェーダーとCanvas 2D代替描画。
- `src/app.js` — 9音構成、音階、操作、状態、画面サイズ、保存、LAB。
- `src/style.css` — レスポンシブGUIと操作パネル。
- `src/body.html` — GUI構造。
- `build.py` — ソースから単体HTMLを再生成。
- `screens/` — 確認画面（Canvas代替描画）。

## テスト状況と制約

- Chromiumで844×390、667×375、1280×720、390×844を表示し、読み込み後のJavaScript例外がないことを確認。
- 音数切替、画面操作、Move→Reset、設定パネル、音階、Lab、Web Audioの発音開始をブラウザで確認。
- **この実行環境ではWebGLのGPUコンテキストが取得できないため、WebGLシェーダーの実描画は未検証です。** 添付スクリーンショットは2D代替描画。WebGL 2/1のシェーダーは実装していますが、端末実機で確認してください。
- **iPhone Safari実機の同時タップ、音量バランス、負荷、発熱は未検証**。ユーザーの端末での再生評価が必要。
- LABの「empty」は操作ログであり、誤タップの確定値ではありません。タッチ直径と間隔はCSS pxの幾何値です。
- SAVEはWebページのオリジンに依存するため、一部のプレビュー環境ではストレージ使用が拒否される場合があります。通常のHTTPS公開が推奨です。

## 技術的に重要な設計判断

1. 音声グラフと視覚表現を切り離し、WebGLで描画を変更しても音色の変化を抑える。
2. Move操作時のタッチ位置と視覚形状は、同じ座標を使って判定する。
3. Float/Orbitでタッチターゲットが漂って子供が誤タッチすることを避けるため、アニメーションは図形の角度と付随光のみ。
4. iPhoneのGPUメモリと描画負荷のため、DPRを最大1.6に制限。静止時は必要なフレームのみ再描画。
5. 今後はSpaceとBondを、発音と独立したより複雑な音響プロセッサへ段階的に発展させられる。
